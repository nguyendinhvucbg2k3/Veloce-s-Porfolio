- **Chuẩn Nhận diện Thương hiệu Veloce:** Logo vector `.SVG` gốc, bảng màu *Abyss Navy – Veloce Blue – Electric Cyan*, bộ font **Chakra Petch / Be Vietnam Pro / JetBrains Mono**.

- **Booking & Tải tài liệu PDF:** Form gửi yêu cầu nhanh, 1-click Copy Email / SĐT / Discord và tải trực tiếp 3 tài liệu PDF chính thức.

## Cách chạy & Triển khai (Deploy)
- **Mở trực tiếp trên máy:** Nhấn đúp vào file `index.html` để mở bằng Chrome / Edge.
- **Đưa lên mạng miễn phí (GitHub Pages):**
  1. Tải toàn bộ thư mục này lên repository GitHub.
  2. Vào **Settings → Pages → Branch: `main` (`/root`) → Save**.
  3. Sau 1–2 phút, website sẽ hoạt động công khai.
- **Hoặc kéo thả lên Netlify Drop:** Truy cập `app.netlify.com/drop` và kéo thả nguyên thư mục vào.
